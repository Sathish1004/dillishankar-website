# Dilli Shankar Digital Marketing Agency Website

A premium, high-end, dark-themed website built using only HTML, CSS, and Vanilla JavaScript.

## 🚀 Features
- **Modern UI/UX**: Dark mode with #29A5E3 blue accents.
- **Glassmorphism**: Soft shadows and rounded corners.
- **Animations**: Intersection Observer for scroll-triggered fade-ups.
- **Responsive**: Mobile-first design for all devices.
- **Clean Structure**: Separate CSS and JS files.

## 📁 Structure
- `index.html`: Home page with Hero, Stats, Services, Testimonials.
- `about.html`: Agency mission and team.
- `services.html`: Detailed service offerings.
- `portfolio.html`: Case studies and results.
- `blog.html`: Marketing insights.
- `contact.html`: Form and location info.
- `css/style.css`: Core design system.
- `js/main.js`: Interactivity and animations.
- `assets/images/`: Generated AI assets for the hero and portfolio.

## 🛠 Tech Stack
- HTML5
- CSS3 (Flex & Grid)
- Vanilla JavaScript
- Lucide Icons (via CDN)
- Inter Font (Google Fonts)

## 💻 How to Run
Simply open `index.html` in any modern web browser.
